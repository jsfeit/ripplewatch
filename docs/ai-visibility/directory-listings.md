## Short description (~300 characters)
Ripplewatch is an MCP server that watches your competitors' pricing, hiring, press and product changes and scores each one against your positioning and your win/loss history. Ask what changed this week, which competitor is heating up, or tell it how a deal went. $29/month plus prepaid usage.

## Longer description
Ripplewatch Connect is a remote MCP server for competitive intelligence. Add one URL as a custom connector in Claude or ChatGPT, sign in, and ask in the chat you already use.

- "What changed with my competitors this week?" gets a short briefing led by the move that matters most to you.
- "Is Acme's new pricing something we should respond to?" gets an answer scored against your positioning.
- "We lost a deal to Acme on price. Log it." records the outcome, and later answers use it.
- "Which competitor is heating up fastest?" returns Heating up, Steady, Cooling or Gone quiet for each one.

It reads public information about the competitors you choose plus what you tell it. It can't see private competitor data and can't change billing.
