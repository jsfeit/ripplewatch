**Title:** Ripplewatch: a competitive intelligence MCP server you can add in one click

**Body:**

I built a hosted MCP server that answers one question: which of your competitors are heating up, and is it costing you deals?

It watches competitor pricing, hiring, launches and news, gives each competitor a Momentum score, and checks that against the wins and losses you tell it about. So instead of a dashboard you ask Cursor things like "what changed with my competitors this week?" or "why are we losing to Brightwell?" and get an answer grounded in your own deal history. You can also log a deal just by saying "we lost that one to Linear because of docs", and it records it.

It's a remote server with OAuth, so there's nothing to install or run locally. There's a one-click button on the setup page, or paste this into mcp.json:

{"mcpServers": {"ripplewatch": {"url": "https://www.ripplewatch.ai/api/mcp"}}}

Setup page: https://www.ripplewatch.ai/connect/claude-and-chatgpt
Repo with the tool list: https://github.com/jsfeit/ripplewatch-mcp

It costs $29 a month plus prepaid usage, and there's a free read on one competitor with no signup. I'd like to hear which tools you'd actually use and which feel pointless. The directory listing is stuck behind Cursor's scanner outage right now, so this is the way in until that's fixed.
